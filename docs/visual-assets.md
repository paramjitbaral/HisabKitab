# HisabKitab artwork

The Android app bundles these images in `app/src/main/res/drawable-nodpi/`:

- `home_cafe.png`: home header.
- `onboarding_ledger.png`: history and profile headers.
- `dashboard_wall.png`: outstanding loans header.
- `add_loan_clipped.png`: loan form background, with the white paper and brass clip.
- `intro_ledger.png`, `intro_history.png`, `intro_private.png`: onboarding backgrounds.

The artwork was generated from the supplied design references; it is not the original reference photography. Inputs, buttons, headings and actual loan records are rendered by the app. The illustrated records inside the onboarding phone image are sample artwork.

The book icon is a vector asset. The system launch screen uses a white book on green. Screens use consistent sans-serif text and white content surfaces.

`image.png` at the repository root is the original MiniLedger showcase retained in the README. Current HisabKitab screenshots are in `releases/HisabKitab/store-assets/`.
